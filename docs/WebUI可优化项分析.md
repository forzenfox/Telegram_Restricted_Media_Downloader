## 1. 背景与范围

对已部署的 WebUI（https://trmd.forzenfox.com）四个页面进行实测访问，分析布局现状并输出可优化项。**本文档只做分析，不涉及代码修改。**

### 1.1 分析方式

- 内部浏览器真实访问，获取页面快照 + 全页截图 + DOM 结构
- 控制台日志检查（发现 Tailwind CDN 警告、Cloudflare beacon 加载失败）
- 结合前端源码（files.js 等）核对交互逻辑

### 1.2 页面清单

| 页面 | 路由 | 核心模块 |
|------|------|----------|
| Dashboard | index.html | 4 张统计卡 / 快捷操作 / 最近任务表 |
| 任务管理 | tasks.html | 双层筛选（状态×类型）/ 任务表格 |
| 文件管理 | files.html | 面包屑 / 排序工具栏 / 文件表格 |
| 系统配置 | config.html | 6 个 Tab（基础/下载/上传/代理/通知/资源限制）|

---

## 2. 布局现状概览

四页统一采用「固定侧边栏 + 主内容区」深色主题布局（Tailwind Slate 色板）：

```
┌─────────┬──────────────────────────────────────┐
│ 侧边栏   │  顶部栏（页面标题 + 状态/刷新按钮）      │
│ TRMD    ├──────────────────────────────────────┤
│ ▸Dashboard│  主内容区（卡片式布局）               │
│ ▸任务管理│                                      │
│ ▸文件管理│                                      │
│ ▸系统配置│                                      │
│         │                                      │
│ 用户/在线│                                      │
└─────────┴──────────────────────────────────────┘
```

| 维度 | 现状评估 |
|------|----------|
| 信息架构 | 三层导航清晰：系统级（侧边栏）→ 页面级（标题）→ 内容级（面包屑/卡片）|
| 色彩语义 | 全局统一：蓝=主操作/进行中、绿=成功、黄=警告、红=危险 |
| 状态-操作一致性 | 任务行操作按钮与状态强关联（执行中→取消、已完成→删除）✅ |
| 敏感字段保护 | 系统配置中 API ID/Hash/Bot Token 已掩码 ✅ |

## 4. 可优化项清单

### 4.1 高优先级（体验/功能缺陷）

| # | 优化项 | 位置 | 现状 | 建议方案 |
|---|--------|------|------|----------|
| H1 | 超长文件名整行换行 | 文件管理 | 文件名超长时占用 2 行高度，行高不统一，破坏表格扫描效率；且部分文件名含敏感内容完整展示有合规风险 | ✅ **已实施**（v1.2）：文件（非目录）名称单行截断（`text-truncate`）+ hover 完整名 Tooltip（`tooltip` 类 + `:data-tooltip`）|
| H2 | 批量操作缺失 | 任务管理 | 任务表格无复选框，只能逐行 取消/删除 | ✅ **已实施**（v1.2）：表头全选 + 行复选框 + 批量操作栏（已选计数/批量取消/批量删除/清除选择），选中后显示 |
| H3 | 空状态设计 | 全部页面 | 任务/文件页已有简单空态（"暂无任务"/"暂无文件"），缺引导 CTA；Dashboard 最近任务为空时无提示 | ✅ **已实施**（v1.2）：任务页区分「无任务（新建任务 CTA）」与「筛选无结果（清除筛选按钮）」；文件页空态加引导 CTA；Dashboard 最近任务空态加 CTA |

> **已核实为已实现项（从开发清单移除）**：H4 保存按钮位于顶栏（config.html 有改动时显示，首屏可见）；H5 URL token 清理已在 [api.js](module/web/js/api.js#L50-L54) `_cleanUrlToken()` 实现；M2 Dashboard 进度条状态色联动（>90% 红 / >70% 黄）已实现。

### 4.2 中优先级（体验打磨）

| # | 优化项 | 位置 | 建议方案 |
|---|--------|------|----------|
| M1 | 统计卡信息密度不足 | Dashboard | 磁盘/内存/CPU 卡增加趋势迷你图（Sparkline），比纯数值更有信息量 |
| M2 | ~~状态色未联动~~ | ~~Dashboard/任务~~ | **已实现**：Dashboard 进度条 >90% 红 / >70% 黄联动，任务进度条 success/error 色已存在 |
| M3 | 时间展示无相对性 | 任务/文件 | 创建时间增加相对时间（「2 小时前」）tooltip |
| M4 | 类型筛选标签过多 | 任务管理 | 7 个类型标签在窄屏易换行，低频类型（监听下载/转发）收入「更多」下拉 |
| M5 | 掩码字符不一致 | 系统配置 | `***` 与 `...` 混用，统一为 `••••`；表单顶部加「* 为必填项」图例 |
| M6 | 交互状态不完整 | 全局 | 补齐 hover 过渡动画、行 hover 高亮、按钮 loading/disabled 态 |
| M7 | 排序偏好不记忆 | 文件管理 | 排序字段/方向用 localStorage 持久化 |
| M8 | 任务状态无微动画 | 任务管理 | 状态切换时进度条流动、状态标签切换动画 |

### 4.3 低优先级（细节/规范）

| # | 优化项 | 说明 |
|---|--------|------|
| L1 | 次要文字对比度 | `#94a3b8` 在卡片背景上对比度接近 WCAG AA 边界，可提亮 |
| L2 | 卡片边界弱化 | 仅靠背景色差区分层级，可加 1px 细边框强化 |
| L3 | 圆角体系 token 化 | 统一按钮 6-8px / 卡片 12-16px 规范 |

### 4.4 技术层面问题

| # | 问题 | 影响 | 建议 |
|---|------|------|------|
| T1 | 生产环境使用 Tailwind CDN（cdn.tailwindcss.com）| 官方明确警告不应用于生产；加载慢、无法 tree-shaking、依赖外部网络 | 改为本地构建产物（或保留 CDN 但明确接受离线不可用）|
| T2 | Cloudflare beacon.min.js 加载失败 | 控制台报错，污染日志，无功能影响 | 移除或换用本地统计 |
| T3 | 智能轮询机制 | 已实现「检测活跃任务→10s 轮询→空闲停止」，设计良好 | 无需改动 ✅ |
| T4 | 生产环境页面切换时弹框闪现闪烁 | 弹框/遮罩由 x-show 控制，Alpine 初始化前默认可见；生产静态资源加载慢于首帧渲染导致 FOUC，页面加载完成即恢复 | 已修复 ✅：fixed 覆盖层统一加 x-cloak，style.css 提供 [x-cloak] 隐藏规则；契约测试 TestOverlayFOUC 强制校验 |

## 5. 响应式断点建议

```
≥1280px : 4 列统计卡，侧边栏常驻
1024-1279 : 统计卡 2×2，侧边栏可折叠
768-1023 : 统计卡 2×2，侧边栏收为抽屉 + 汉堡按钮
<768px  : 统计卡单列，表格横滚或转卡片式
```

## 6. 实施建议

1. **优先级排序**：H1-H5 为核心体验项，建议先行；M 系列按投入产出逐个推进；L 系列随代码改动顺带处理。
2. **改动边界**：除 T1 外，本文档不改变后端 API 契约与页面路由，均为前端渲染/交互层调整。
3. **后续更新**：任一优化项落地后，回写本文档状态与对应 PRD/设计文档，防止文档与实现漂移。
